# Continuous Information Stream

> Source: บทสนทนากับบอส วันที่ 2026-10-22

แนวคิด: สร้างระบบติดตามข้อมูลแบบไหลต่อเนื่องจากหลายแหล่ง ไม่จำกัดเฉพาะ X โดยรวบรวมข้อมูลใหม่ คัดกรองความซ้ำและความน่าเชื่อถือ จัดลำดับความสำคัญ แล้วสรุปเป็นฟีดที่อ่านง่าย

## Key Points

- แหล่งข้อมูลอาจประกอบด้วย RSS, เว็บไซต์ข่าว, บล็อก, changelog, GitHub, Reddit, YouTube และ API ที่อนุญาต
- ระบบควรใช้ polling หรือ webhook ตามความเหมาะสม ไม่ควรอ้างว่าอ่าน “ทุกโพสต์บนอินเทอร์เน็ต” ได้จริง
- ต้องมีชั้น deduplication, relevance filtering, source credibility และ timestamp
- ควรแบ่งโหมดเป็นดึงเมื่อถาม, สรุปตามรอบเวลา และแจ้งเตือนเฉพาะเหตุการณ์สำคัญ
- ในแชตปัจจุบัน สลี่ไม่สามารถเฝ้าเว็บแบบผลักข้อความเองได้ตลอดเวลาโดยไม่มีตัวกำหนดการหรือบริการเบื้องหลัง แต่สามารถสร้าง workflow ด้วย scheduler/โปรแกรมเฝ้าติดตามได้
