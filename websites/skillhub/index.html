📥 แนะนำการติดตั้งและเรียกดู

ฐานสกิลนี้เป็น static HTML — ไม่ต้องติดตั้งอะไรเลย เปิดผ่านเบราว์เซอร์ได้ทันที

วิธีที่ 1 — เปิดโดยตรง (ง่ายสุด)

กดปุ่ม ⚡ เปิดดูทุกสกิล ด้านบน หรือเปิดไฟล์นี้ในเบราว์เซอร์:

file:///data/data/com.termux/files/home/cow/websites/skillhub/index.html

วิธีที่ 2 — เปิดผ่านเว็บเซิร์ฟเวอร์ (แนะนำ)

เปิดด้วย HTTP server ธรรมดา เพื่อไม่ให้ browser บล็อกไฟล์ local:

cd ~/cow/websites/skillhub
python3 -m http.server 8088
# แล้วเปิด http://localhost:8088 ในเบราว์เซอร์

วิธีที่ 3 — เชื่อมจาก NovaAgent

ถ้า NovaAgent gateway รันอยู่ ให้วางไฟล์ไว้ใน static/ แล้วเปิดผ่าน:

http://127.0.0.1:9899/skillhub/index.html

สร้าง Launcher บนหน้าจอ

สร้าง shortcut เปิดฐานสกิลด้วยคำสั่งเดียว (Android / Termux):

# สร้างไฟล์ ~/cow/skillhub-launcher.sh
cat > ~/cow/skillhub-launcher.sh <<'EOF'
#!/data/data/com.termux/files/usr/bin/bash
xdg-open "file:///data/data/com.termux/files/home/cow/websites/skillhub/index.html" 2>/dev/null || am start -a android.intent.action.VIEW -d "file:///data/data/com.termux/files/home/cow/websites/skillhub/index.html" 2>/dev/null || echo "เปิดที่: ~/cow/websites/skillhub/index.html"
EOF
chmod +x ~/cow/skillhub-launcher.sh

cd ~/cow/websites/skillhub && python3 build.py

alias skillhub='cd ~/cow/websites/skillhub && python3 build.py && echo "✅ อัปเดตแล้ว (88 สกิล)"'
