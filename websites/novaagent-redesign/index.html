Privacy

Radical Transparency — บอกตรงๆ

ไม่มีการเคลมที่ขัดแย้งในตัวเอง บอสบอกได้ว่าอะไรถูกเก็บ อะไรไม่ถูกเก็บ

✓ ข้อมูลที่อาจถูกจัดเก็บ

  • ✓ บทสนทนาและข้อมูล memory อาจถูกบันทึกตามค่าการเก็บข้อมูลของระบบ
  • ✓ บาง session อาจมีอายุเก็บต่างกัน; การลบ session, memory และ knowledge เป็นคนละขั้นตอน
  • ✓ ข้อความที่ส่งให้โมเดลจะถูกส่งไปยัง provider ที่เลือก เว้นแต่ใช้โมเดล local
  • ✓ ตรวจการตั้งค่า provider และนโยบายของ provider ก่อนส่งข้อมูลอ่อนไหว

! ข้อจำกัดที่ควรรู้

  • ! ผู้ให้บริการโมเดลอาจมีนโยบายเก็บ/ใช้ข้อมูลของตนเอง ซึ่งต่างกันตามบริการและบัญชี
  • ! ระบบมี log บางประเภท; อย่าส่ง secrets หรือข้อมูลส่วนตัวที่ไม่จำเป็น
  • ! การลบข้อมูลต้องตรวจชนิดข้อมูลและช่องทางที่จัดเก็บแยกกัน
  • ! ข้อความนี้อธิบายโค้ดที่ตรวจ ณ วันที่จัดทำ ไม่ใช่การรับประกันจาก provider
